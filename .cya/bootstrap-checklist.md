# Agent/Chat Bootstrap Checklist

Before starting a new substantial task in CYA Hub v10:

- [ ] Read Project Instructions.
- [ ] Read `CURRENT.md`.
- [ ] Read `.cya/project-state.yaml`.
- [ ] Read `.cya/tool-registry.yaml`.
- [ ] Review the living Tool Guide in Google Drive.
- [ ] Confirm the action is already registered.
- [ ] If missing, register it before execution.
- [ ] Decide immediate vs deferred.
- [ ] Produce TOOL PLAN when technical.
- [ ] Execute the minimum scoped change.
- [ ] Validate using the correct tool.
- [ ] Record evidence.
- [ ] Update project state after meaningful progress.
